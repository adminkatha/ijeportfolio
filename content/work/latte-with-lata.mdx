<FillIn>time, budget, tools or data constraints</FillIn>

## Architecture

A static site, built by the team without a framework:

- hand-written HTML, with CSS split into design tokens, a base layer and one stylesheet per section;
- JavaScript modules, with GSAP (ScrollTrigger, SplitText) for the scroll and title animations and Splide for the carousels;
- hosted on GitHub Pages.

## Implementation

What the site shows, top to bottom:

- an animated title, "Latte with Lata: Real Conversations. Built on Purpose.";
- the café's story, "From First Pour to Last Word";
- the menu, with **See the Menu** and **Book a Table**;
- the latest episodes, each with its guest, date and running time, and **All Episodes**;
- the host's page, "Meet Lata";
- a footer with opening hours, the podcast's channels (Spotify, Apple Podcasts, YouTube, RSS) and the site's sections.
