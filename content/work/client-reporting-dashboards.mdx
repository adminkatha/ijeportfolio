## Context

Five businesses use the same system: an online clothing and jewellery shop (Honey Tribe), an e-bike brand (MeloYelo), an RV resort (Riverdance RV Resort), a rooming-house property brand (Rooming House Expert) and The Contract Shop, which generates leads with a business quiz. Each client opens one dashboard page inside a client portal.

## Constraints

- Data comes from many places: Meta and Shopify through Windsor.ai, ActiveCampaign, Campaign Monitor, Klaviyo, sales and stock records, and a quiz feed.
- The JavaScript is kept ES5-safe and passes an esprima syntax check before every deploy.

## Architecture

- **One page per client:** HTML with inline CSS and hand-written vanilla JavaScript, served from the client's own path in the portal.
- **One data file per client:** a Python export job pulls the client's sources and writes a `data.json` next to the page. A Sync button asks the server to refresh it.
- **Everything is drawn in the browser** from that file: KPI cards, tables, and every chart as inline SVG.

## Implementation

Every dashboard is built from the same parts:

- a header with a "data through" stamp;
- period presets, plus a separate benchmark period that every KPI is compared against;
- day, week or month grain, and relative or absolute chart axes;
- KPI scorecards with deltas against the benchmark;
- time-series and breakdown charts, sortable tables and the ads that ran;
- written "reading of the period" insight cards.

The tabs follow each business:

- **Honey Tribe:** Shopify sales, a Shopify × Meta funnel, product and audience.
- **MeloYelo:** sales against the financial-year bike target, riders and leads (with speed-to-lead per agent), inventory and production, marketing.
- **Riverdance RV Resort:** paid social against industry benchmarks, and email.
- **Rooming House Expert:** the Meta funnel, email, the lead magnet and its email sequence, demographics and placements.
- **The Contract Shop:** quiz-lead conversion diagnostics, and Meta lead generation.

## Key technical decision

No framework and no chart library: each page is plain HTML, CSS and JavaScript that draws its own SVG charts from one JSON file.
